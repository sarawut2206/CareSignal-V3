# CareSignal V3 — ลูกหลานวัดแรงขาให้ผู้สูงอายุที่บ้าน

> รุ่นที่ปรับหลังฟังผู้ใช้: ไม่ใช้กล้อง ลูกหลานเป็นคนจับเวลาแบบทดสอบมาตรฐาน 3 ท่า ด้วยเกณฑ์เดียวกับรุ่นกล้อง (V2)

🔗 ใช้งาน: https://sarawut2206.github.io/CareSignal-V3/ · รุ่นกล้อง: https://sarawut2206.github.io/CareSignal-V2/

## ทำไมต้องมี V3

ภารกิจ Idea Validation (15–16 ก.ย. 2569) สัมภาษณ์ผู้สูงอายุ 3 คน (อายุ 60, 65, 68) และลูกหลานผู้ดูแล 2 คน:

- 5/5 มีผู้สูงอายุหกล้มในปีที่ผ่านมา · 5/5 อยากประเมินได้ที่บ้าน
- 3/3 ผู้สูงอายุติดตั้งแอปหรือตั้งกล้องเองไม่ได้ ("กดไม่เป็น" · "ตั้งกล้องไม่เป็น")
- 3/3 ผู้สูงอายุเลือก "ให้ลูกหลานรู้" เป็นฟีเจอร์อันดับ 1

จึงเปลี่ยนผู้ใช้จากผู้สูงอายุเป็นลูกหลาน และยกทางสำรอง "จับเวลาด้วยมือ" ของ V2 ขึ้นเป็นทางหลัก

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าหลัก: ก่อน → สิ่งที่พบ → หลัง และตารางเทียบ V2/V3 |
| `app.html` | แอปสำหรับลูกหลาน 4 ส่วน: ลงทะเบียน · วิธีวัด · วัดวันนี้ · แนวโน้ม (+ บันทึกว่าล้ม, ใบสรุปพิมพ์ได้, แชร์ LINE) |
| `testkit.html` | ชุดอุปกรณ์ทดสอบพิมพ์ได้ 3 แผ่น: ของที่ต้องมี · ขั้นตอนติดผนัง · บทวิดีโอสาธิต |
| `cs-score.js` | เกณฑ์คะแนน ยกตัวเลขจาก V2 ทุกตัว (10.0/11.5/12.1 วินาที · MCID 2.3 วินาที · TUG ≥ 12 · ยืนต่อเท้า < 10) |
| `cs-hospitals.js` | รายชื่อโรงพยาบาลจาก V2 |
| `test/test_score.mjs` | `node test/test_score.mjs` — 28 ข้อ ตรวจเกณฑ์และถ้อยคำที่ห้ามอ้างเกินจริง |

## หลักการเดิมที่ยังอยู่

- ไม่วินิจฉัยโรค ไม่แทนการพบแพทย์ · ฉุกเฉินโทร 1669 ไม่มี "ทีมฉุกเฉิน" ของระบบ
- ข้อมูลอยู่ในเครื่องของลูกหลาน (`localStorage`) ยังไม่ส่งไปที่ใด ลบได้ทุกเมื่อ
- ทุกสัญญาณเสี่ยงแสดงเหตุผลและที่มา ไม่ใช่ AI ทำนาย
- ค่าจับเวลาที่ผิดปกติ (เช่น 0 วินาที) จะถูกถามยืนยันก่อนบันทึก
